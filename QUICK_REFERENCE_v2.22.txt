════════════════════════════════════════════════════════════════════════════════
📊 ESTADO DE PAGO
════════════════════════════════════════════════════════════════════════════════

┌──────────┬─────────────────────────────────────────────┐
│ ESTADO   │ SIGNIFICADO                                 │
├──────────┼─────────────────────────────────────────────┤
│ PAGADO   │ Monto pagado >= monto original              │
│ PARCIAL  │ Monto pagado < monto original               │
│ ANULADO  │ Pago marcado como inválido (por usuario)   │
└──────────┴─────────────────────────────────────────────┘

El script calcula automáticamente basado en:
  monto_adeudado = monto_original - monto_pagado
  si monto_adeudado == 0 → PAGADO
  si monto_adeudado > 0 → PARCIAL

⚠️ ERRORES COMUNES & SOLUCIONES
════════════════════════════════════════════════════════════════════════════════

❌ "Archivo no encontrado: CUOTAS 2025 INSM vigente para cristian.xlsx"
   → Verifica el NOMBRE EXACTO del archivo
   → Debe estar en Google Drive (accesible por Google Apps Script)

❌ "DNI generado como NULL (agotados)"
   → Se agotó el rango de DNIs para esa institución (100k)
   → Usa DNI real en lugar de dejar vacío

❌ "DIVIDIDO sin detalles: DNI ..., CUOTA, MARZO"
   → No existe esa combinación en hoja PAGOS_DETALLES
   → Agrega fila: 12345678 | CUOTA | MARZO | monto | metodo | talonario

❌ "Error INSERT batch: 400"
   → DNI > 20 caracteres
   → APELLIDO o NOMBRES > 200 caracteres
   → TELÉFONO > 20 caracteres
   → El script lo valida y SALTA esa fila (ver SKIPPED_DETAILS)

❌ "Encontrados: 0/45 estudiantes"
   → Esperó 15s pero estudiantes aún no se insertaron
   → Aumentar tiempo en Utilities.sleep(15000) a 30000

❌ "No hay logs disponibles"
   → Primera ejecución no tiene resultados
   → Ejecuta nuevamente después de la 1ra sincronización

⚡ OPTIMIZACIONES IMPLEMENTADAS
════════════════════════════════════════════════════════════════════════════════

✅ Batch Processing
   - cargarPagos: 1000 pagos por query
   - procesarEstudiantes: 50 estudiantes por batch
   - buscarEstudiantes: 50 DNIs por RPC call
   - insertarPagos: 20 pagos por POST
   - insertarPagosMultiples: 1 RPC por pago múltiple

✅ Parallel RPC Calls
   - search_estudiantes_by_dni (batch de 50)
   - search_pagos_by_estudiantes (batch de 10)
   - insertar_pago_multiple_con_detalles_upsert (1 por 1, pero batch en DB)

✅ Delay Management
   - DELAY_MS = 200 entre batches (evita rate limit)
   - Utilities.sleep(1000) entre chunks grandes
   - Utilities.sleep(15000) después de insertar estudiantes

✅ Error Handling
   - muteHttpExceptions: true (no falla por timeout)
   - Try/catch en loops (continúa si 1 fila falla)
   - SKIPPED_DETAILS por cada error
