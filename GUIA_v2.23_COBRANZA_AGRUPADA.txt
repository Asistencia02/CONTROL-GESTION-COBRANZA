FUNCIONES PRINCIPALES
================================================================================

1️⃣ ejecutarCobranzaAgrupada()
   └─ Función manual del menú (🔄 SINCRONIZACIÓN COBRANZA → ▶️ EJECUTAR)
   └─ Muestra UI y resultado en alerta

2️⃣ ejecutarCobranzaInterna()
   └─ Lógica real (sin UI)
   └─ Llamada por ejecutarCobranzaAgrupada()

3️⃣ normalizarExcelParaCobranza()
   └─ Lee Excel origen
   └─ Extrae estudiantes + conceptos pagados
   └─ Retorna: { inst_id: { estudiantes: { dni: data } } }

4️⃣ procesarHojaCobranza()
   └─ Por cada hoja:
      ├─ Lee cada fila (1 estudiante)
      ├─ Recolecta TODOS los conceptos pagados (INSCRIPCION + CUOTA + SEGURO)
      └─ Almacena en estudiantesMap[dni].conceptos[]

5️⃣ procesarCobranzaPorInstitucion()
   └─ Insert estudiantes
   └─ Buscar en BD
   └─ Cargar configuración
   └─ Cargar conceptos
   └─ CREAR PAGOS MÚLTIPLES

6️⃣ crearPagoMultipleAgrupado() ⭐ LA FUNCIÓN CLAVE
   └─ Toma 1 estudiante + sus conceptos pagados
   └─ Busca concepto_id en BD
   └─ Busca monto_original en configuracion_carreras
   └─ Crea JSON de detalles:
      [
        { concepto_id: 15, monto_original: 5000, monto_pagado: 5000 },
        { concepto_id: 16, monto_original: 2500, monto_pagado: 2000 },
        { concepto_id: 17, monto_original: 600, monto_pagado: 500 },
        ...
      ]
   └─ Llama RPC insertar_pago_multiple_con_detalles_upsert
   └─ ✅ Crea 1 pago_multiple + N detalles

CÓMO USAR
================================================================================

1. Copiar google-apps-script-v2-23-COBRANZA-AGRUPADA.gs
   └─ A: Google Sheet → Extensions → Apps Script

2. Preparar Excel con estructura correcta
   └─ 5 hojas: ANALISTA2026, HIGIENE2026, etc.
   └─ Columnas: DNI, APELLIDO, NOMBRES, INSCRIPCION, CUOTA MARZO, etc.
   └─ Datos: montos pagados por estudiante

3. Ejecutar
   └─ Google Sheet → 🔄 SINCRONIZACIÓN COBRANZA → ▶️ EJECUTAR COBRANZA AGRUPADA

4. Ver resultado
   └─ Alerta muestra:
      ✅ COBRANZA COMPLETADA
      📦 INSTITUCIÓN 1:
         ✅ Estudiantes procesados: 45
         💰 Pagos múltiples creados: 45
         📊 Conceptos agrupados: 385
         ⚠️ Errores: 0
   
   └─ Hoja: LOG_SINCRONIZACION (resumen por institución)
   └─ Hoja: SKIPPED_DETAILS (errores: DNI vacío, APELLIDO vacío, etc.)

5. Verificar en Supabase
   └─ Supabase → pagos_multiples (debe haber N nuevos registros)
   └─ Supabase → pagos_multiples_detalle (debe haber N*M detalles)

6. Ver en Frontend React
   └─ RegistroPagos debe mostrar los pagos (cargados como pago_multiple)
   └─ Mira ModalConfirmacionCobro: muestra conceptos + monto_final

COMPARATIVA: EXCEL vs BD vs SUPABASE
================================================================================

EXCEL (lo que el usuario ingresa):
  DNI: 12345678
  INSCRIPCIÓN: $5000 (cuánto pagó)
  CUOTA MARZO: $2000 (cuánto pagó)
  ...
  TOTAL: $19,000

BD (configuracion_carreras, lo que DEBE pagar):
  monto_inscripcion: $5000
  monto_cuota: $2500
  monto_seguro: $600
  ...
  TOTAL DEBIDO: $23,600

SUPABASE (lo que se REGISTRA):
  pago_multiple: 
    monto_total: $19,000 (lo que pagó)
    cantidad_conceptos: 13
  
  pagos_multiples_detalle (para cada concepto):
    monto_pagado: $2000 (lo que pagó en CUOTA MARZO)
    monto_original: $2500 (lo que DEBÍA pagar)

RESULTADO:
  Adeudado = $23,600 - $19,000 = $4,600

================================================================================
ERRORES COMUNES & SOLUCIONES
================================================================================

❌ "Archivo no encontrado: CUOTAS 2025..."
   → Verifica el NOMBRE EXACTO del Excel
   → Debe estar en Google Drive (accesible por Apps Script)

❌ "Estudiantes procesados: 0"
   → No encontró estudiantes con conceptos pagados
   → Verifica que Excel tiene montos > 0 en INSCRIPCIÓN, CUOTA, SEGURO

❌ "Pagos múltiples creados: 0"
   → Los RPC fallaron
   → Revisar Logs (View → Logs) para error exacto
   → Verificar que BD tiene conceptos_pago configurados

❌ "Encontrados: 0/45"
   → Esperó 15 segundos pero estudiantes NO se insertaron
   → Aumentar Utilities.sleep(15000) a 20000 o 30000

✅ Contactar si error persiste: revisar Supabase logs + BD estructura
